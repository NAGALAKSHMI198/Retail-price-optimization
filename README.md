# 🛒 Retail Price Optimization using Machine Learning

An end-to-end Machine Learning project that predicts optimal retail product prices using historical sales and pricing data. The project includes data preprocessing, model training, evaluation, and an interactive Streamlit web application for real-time price prediction.

## 🚀 Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Regression-based price prediction
- Machine Learning model training
- Interactive Streamlit application
- User-friendly prediction interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## 📁 Repository Structure

```
Retail-Price-Optimization/
│
├── app.py                 # Streamlit application
├── main.py                # Model training
├── reatail.csv            # Dataset
├── README.md
```

## 🎯 Objective

The goal of this project is to demonstrate how machine learning can assist retailers in optimizing product prices by analyzing historical pricing data and generating accurate price predictions.
